ETAPA 1 — CONFIGURAÇÃO DO EQUIPAMENTO

Configure o SENS antes de instalar

Os campos abaixo serão gravados na NVS do ESP32 após a instalação. A Rev.15D2.3 recebe a configuração completa em uma transação lógica, persiste somente no COMMIT e confirma pela releitura da própria NVS.

Identificação e operação
CATÁLOGO — sensores de configuração rápida
Perfil do catálogo: 450 pulsos/L • janela 1000 ms • saída Vazão — L/min. Somente o GPIO é configurável.
Catálogo = conveniência. Instrumentos fora do catálogo entram por INTERFACE / DRIVER ou CONVERSOR.
INTERFACES / DRIVERS
UART
UART GENÉRICA — preparação
Firmware Rev.03M: o T6613 continua funcional pelo driver UART consolidado. Os campos abaixo preparam/documentam uma futura UART genérica, mas ainda não ativam leitura científica de protocolos arbitrários no firmware.
CONVERSORES
ADC-I²C / ADS1115
Firmware Rev.03M: ADS1115 já é operacional para CO₂/ppm. Outras grandezas podem ser selecionadas abaixo para preparar/documentar a configuração, mas só passam a ser saída científica quando o firmware ganhar o mapeamento genérico correspondente.
Compatibilidade do conversor legado preservada no FW03M.

SENSOR GENÉRICO — slots configuráveis

GENERIC_SENSOR V1: configure sensores que não existem no catálogo usando motores já incorporados ao firmware. Para o primeiro ensaio, use I2C_GENERIC. O firmware não identifica o sensor pelo nome/modelo.

Correção metrológica — y = a × x + b

2 correções metrológicas disponíveis. Escolha o sensor/canal habilitado e depois a grandeza. Vale para sensores nativos e genéricos. Linhas OFF e vazias são ignoradas.
Separador decimal: use ponto (.) nos coeficientes, por exemplo a = 1.0234 e b = -12.5. Não use vírgula.

Preencha e guarde a configuração antes da instalação.
ETAPA 2 — INSTALAÇÃO

Instale o SENS

O Wi‑Fi automático do ESP Web Tools está desativado nesta versão. Terminada a instalação, use a Etapa 3: ela grava automaticamente o Nome + Serial já salvos e, na mesma conexão USB, segue para a rede.

ATUALIZAR — PRESERVAR DADOS: mantém NVS/identidade do equipamento (Epoch, próximo Seq e configurações). Se o gravador apresentar uma opção de apagar dados, escolha NÃO APAGAR / manter dados.
ETAPA 3 — GRAVAR CONFIGURAÇÃO SENS

Envie a configuração salva ao ESP32

Depois de instalar, clique uma vez abaixo e selecione a porta do ESP32. O Installer grava Nome + Serial juntos e, na Rev.15D2.3, envia a configuração completa por uma transação atômica: Básico + Avançado + Genérico 1/2 + Correção 1/2. O firmware só confirma após COMMIT, releitura da NVS e snapshot válido.

Aguardando instalação e conexão com o ESP32.
ETAPA 4 — REDE • ÚLTIMA ETAPA

Configure o Wi‑Fi

A configuração SENS termina completamente na Etapa 3. Para configurar a rede, clique em PREPARAR WI‑FI, selecione novamente a porta do ESP32 e então escolha uma rede detectada ou digite o SSID manualmente.

Conclua a Etapa 3 antes de configurar o Wi‑Fi.
CONFIGURAÇÃO GRAVADA NO EQUIPAMENTO

Leitura da configuração runtime

Espelho da configuração enviada e confirmada pela transação atômica da Rev.15D2.3. O COMMIT valida todos os blocos e gera um snapshot persistente relido da NVS. A senha Wi‑Fi nunca é exibida.

ETAPA 5 — MONITOR SENS

Console serial do equipamento

Liberado após o equipamento ficar operacional. O monitor usa Web Serial a 115200 bps. Apenas uma sessão pode usar a porta USB por vez.

Monitor liberado. Clique em ABRIR MONITOR quando quiser diagnosticar o SENS.
